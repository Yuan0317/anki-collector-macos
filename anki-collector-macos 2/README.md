# Mac Anki 英语收集器 Skill

**把英文句子变成带中文翻译和英语语音的 Anki 卡片，再把收集器做成可双击启动的 Mac 应用。**

你可以下载这个项目交给 AI 操作，也可以把完整说明直接复制给 AI。已有能运行的收集器时，优先复用现有环境，不为了生成应用重新下载翻译模型。

## 可以做什么

- 粘贴英文句子，使用 Argos Translate 在本机翻译成中文。
- 检查、修改中文后，确认写入 Anki。
- 默认卡片正面为中文，背面为英文和英语语音。
- 检查本工具已添加过的句子，减少重复卡片。
- 将 Python 收集器包装成可双击的 `.app`，无需每次打开终端。
- 让 AI 检查不同电脑的环境、定位错误，并适配牌组与字段。

**适用范围：macOS。** 本项目提供 Skill、源码模板和应用生成工具；下载后由 AI 根据你的电脑完成配置。它不包含 Python、翻译模型，也不是自带全部依赖的独立安装包。

## 快速开始：选一种方式

### 方式一：下载后交给 AI（推荐）

1. 点击本仓库页面的 **Code → Download ZIP**，下载并解压。
2. 把项目文件夹或 ZIP 交给支持读取文件的 AI。
3. 发送下面这段话：

```text
请阅读并使用这个项目里的 SKILL.md，检查我的 Mac，帮我完成 Anki 英语收集器，并生成可双击启动的应用。
如果已有 ~/anki-collector，请先复用已有脚本、虚拟环境和模型。
启动前必须设置 ARGOS_CHUNK_TYPE=SPACY，不要为了包装应用重新安装大型依赖。
请实际完成你能执行的操作；无法操作我的电脑时，给我逐步可复制的步骤。
完成后告诉我应用在哪里、怎么使用，以及哪些功能已经验证。
```

如果已有收集器，你也可以只说：“帮我把已运行成功的收集器包装成 Mac 应用，保留原有功能。”

### 方式二：复制给任意 AI

打开仓库里的 [复制给AI使用.txt](复制给AI使用.txt)，复制**全部内容**，发给你的 AI。

这个文件包含完整操作说明、收集器源码和应用生成助手；AI 无需访问下载链接。若聊天长度受限，可以按文件分段发送，最后再要求开始操作。

没有电脑操作权限的 AI 只能指导你执行，不能替你完成本机安装。

### 方式三：安装成 Codex Skill

将整个项目文件夹命名为 `anki-collector-macos`，放到：

```text
~/.codex/skills/anki-collector-macos/
```

确认该目录下直接包含 `SKILL.md`，而不是又嵌套一层项目文件夹。已有同名 Skill 时先保留旧版本。

按客户端方式重新加载 Skill 后，发送：

```text
请使用 $anki-collector-macos，帮我把现有 Anki 收集器包装成可双击的 Mac 应用。
```

其他支持 `SKILL.md` 的工具，请按对应工具的安装方式放置文件夹。

## 已有可运行收集器：直接生成应用

如果下面两个文件已经存在且收集器能正常运行，可以直接使用应用生成助手：

```text
~/anki-collector/anki_collector.py
~/anki-collector/.venv/bin/python
```

1. 打开终端，输入 `cd `（末尾有空格）。
2. 将解压后的项目文件夹拖进终端，按回车。
3. 复制执行：

```sh
python3 scripts/build_mac_app.py \
  --project "$HOME/anki-collector" \
  --output "$HOME/Desktop/Anki英语收集器.app"
```

生成的应用在桌面上，双击即可。**已经生成 `.app` 后，不需要再用 Automator 制作一次。** 如果桌面已有同名应用，助手会停止，请换一个输出名称。

项目不在默认目录时，修改 `--project`。解释器或脚本位置不同时，可以指定：

```sh
python3 scripts/build_mac_app.py \
  --project "$HOME/我的收集器" \
  --python "$HOME/我的收集器/.venv/bin/python" \
  --script anki_collector.py \
  --output "$HOME/Desktop/Anki英语收集器.app"
```

`python3` 不可用时，让 AI 先检查本机已有 Python，或改用 Automator。不要仅为了运行这个助手重装整个翻译环境。

## 日常怎么用

1. 打开 Anki，保持运行。
2. 双击「Anki英语收集器.app」。
3. 粘贴英文，点击「翻译成中文」。
4. 检查中文，需要时修改，也可以试听英语。
5. 点击「确认添加到 Anki」，确认后写入卡片。

默认写入「英语学习积累」牌组。模板选择同时具有「正面」「背面」字段的笔记类型。你的牌组或字段不同时，让 AI 先检查并适配，不要直接覆盖现有 Anki 配置。

**请保留原项目目录及 `.venv`。** `.app` 是启动器，运行时仍依赖原脚本、Python 环境和本地模型；移动或删除它们会导致应用无法启动。

## 新电脑需要准备什么

| 项目 | 用途 | 处理方式 |
| --- | --- | --- |
| Python 与匹配的 Tk | 运行程序及图形界面 | AI 检查已有环境，缺少时再安装 |
| Argos Translate | 本地英中翻译 | 优先复用项目虚拟环境 |
| 英中翻译模型及 SPACY 所需资源 | 离线翻译与分句 | 检查本地资源，缺少时再下载 |
| Anki 与 AnkiConnect | 将卡片写入 Anki | Anki 需保持打开，并确保接口可用 |
| Mac 英语声音 | 生成英语语音 | 模板默认 Samantha，可适配可用声音 |

助手启动时固定设置 `ARGOS_CHUNK_TYPE=SPACY`，默认使用 CPU。依赖版本和下载方式由执行任务的 AI 按当前官方文档检查，不把某一台电脑的 Python 版本强加给其他人。

从零准备环境时，可能需要下载较大的模型；已有运行成功的环境时，无需为了生成应用重复下载。

## 出错怎么处理

启动日志位于：

```text
~/Library/Logs/AnkiCollector/launcher.log
```

在访达中按 `⌘⇧G`，输入 `~/Library/Logs/AnkiCollector/`，即可找到日志。

| 现象 | 优先检查 |
| --- | --- |
| 双击后没有窗口 | 日志中的错误、原目录是否移动、Python 和 Tk 是否可用 |
| 翻译失败 | SPACY 启动变量、英中模型及 SPACY 资源是否完整 |
| 添加卡片失败 | Anki 是否打开、AnkiConnect 是否可用、牌组与字段是否匹配 |
| 英语语音失败 | Samantha 或其他英语声音是否可用，以及音频转换报错 |
| 输出应用已存在 | 使用不同名称，或检查旧应用后再处理 |

把实际报错交给 AI，要求它先定位原因，不要一开始就删除虚拟环境重装。首次加载本地翻译模型可能较慢。

## 文件说明

```text
anki-collector-macos/
├── README.md                     给用户看的使用说明
├── SKILL.md                      给 AI 的操作规范
├── 复制给AI使用.txt                可独立复制的完整版本
├── scripts/
│   └── build_mac_app.py          生成双击应用的工具
└── assets/
    └── anki_collector.py         从零创建时使用的收集器模板
```

已有收集器时，模板不应覆盖用户代码。应用生成工具不安装依赖、不修改收集器、不启动程序，也不新增 Anki 卡片。

## 验证范围与限制

- 已检查 Skill 格式及 Python 源码语法。
- 已在现有 Mac 环境中生成测试应用，并检查输出文件保护和应用签名。
- 这些检查不代表每台电脑的依赖、模型和 Anki 设置都已验证。
- 重复检查针对本工具生成的句子标签及 Anki 重复限制，不保证识别所有历史卡片或近义重复。
- 项目默认使用本地翻译和系统语音，通过本机 AnkiConnect 写入卡片；同步到其他设备仍需使用 Anki 自身的同步功能。

分享或提交问题时，请不要上传个人卡片、虚拟环境、模型文件或包含私人句子的日志。
